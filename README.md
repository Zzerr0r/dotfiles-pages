# dotfiles

Public information pages for the owner's personal Google Drive backup client.

Live site: <https://zzerr0r.github.io/dotfiles-pages/>

Google OAuth Branding values:

- App name: `dotfiles`
- Application home page: `https://zzerr0r.github.io/dotfiles-pages/`
- Application privacy policy: `https://zzerr0r.github.io/dotfiles-pages/privacy/`
- Authorized domain: `zzerr0r.github.io`

- `index.html`: application purpose, Google Drive access, and owner contact.
- `privacy/index.html`: privacy and data-handling policy.
- `assets/site.css`: local responsive styles; no third-party fonts or scripts.

GitHub Pages publishes the repository root from `main`, with HTTPS enforced.
`.nojekyll` keeps these plain static files intact. Enter the URLs above in the
Google OAuth client's Branding settings, then switch the Audience publishing
status to In production.

This site contains descriptive information only. It is separate from the actual
configuration, credentials, and encrypted recovery snapshots.
