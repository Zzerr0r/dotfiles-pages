# dotfiles

Public information pages for the owner's personal Google Drive backup client.

- `index.html`: application purpose, Google Drive access, and owner contact.
- `privacy/index.html`: privacy and data-handling policy.
- `assets/site.css`: local responsive styles; no third-party fonts or scripts.

Publish the repository root with GitHub Pages. `.nojekyll` keeps these plain
static files intact. The application homepage and privacy page must be entered
in the Google OAuth client's Branding settings once the site is deployed.

This site contains descriptive information only. It is separate from the actual
configuration, credentials, and encrypted recovery snapshots.
