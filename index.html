Personal laptop recovery

dotfiles

Encrypted recovery backups, stored in the owner's own Google Drive account.

What this application does

dotfiles is a personal command-line backup and restore tool. It preserves selected laptop recovery files in encrypted snapshots and can restore them when the owner replaces a computer.

It uses restic to encrypt backup content locally and rclone to transfer the encrypted objects to Google Drive. This website provides information about the application; it does not upload or restore backups.

Google account access

The owner authorizes a Google Desktop OAuth client with the drive.file permission. The application uses this permission to manage the backup files it creates. It does not request access to Gmail, contacts, or unrelated existing Drive documents.

This application is for its owner's personal use. It does not offer public account registration.

Data handling

Backup content is encrypted before upload. The encryption password remains with the owner. See the privacy policy / Datenschutzerklärung for access, storage, retention, and authorization details.
