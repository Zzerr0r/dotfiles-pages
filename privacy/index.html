Privacy policy

Datenschutzerklärung für die persönliche Anwendung „dotfiles“.

Last updated: 23 October 2026

Application and owner

dotfiles is a personal command-line laptop backup client maintained by Zzerr0r. It is used by the owner with the owner's own Google account. This policy describes the backup client and this informational website.

Google data accessed

The client requests the Google Drive https://www.googleapis.com/auth/drive.file OAuth scope. It creates and manages its own backup objects and reads their contents and metadata when listing, checking, or restoring backups. Operations include creating, reading, updating, and deleting these objects as required for backup storage and repository maintenance.

The client does not request Gmail or contact permissions and does not request broad access to unrelated existing Drive documents.

Purpose and use

Google Drive data is used only to store, verify, manage, and restore the owner's encrypted recovery snapshots. It is not used for advertising, profiling, analytics, sale, or training machine-learning models.

Storage and security

Source files are read on the owner's computer. Restic encrypts backup content and repository metadata locally before rclone uploads them to Google Drive over HTTPS. Decryption happens on the owner's computer using the backup password.

OAuth credentials are stored in a restricted local configuration file and are included only inside the encrypted recovery backup. The backup password is stored separately on the owner's computer and in an offline recovery copy; it is not uploaded as plaintext or published on this website.

Google still processes account, connection, storage, and object information required to provide Google Drive. Google's own processing is described in the Google Privacy Policy.

Sharing

The application transfers encrypted backup objects to the owner's Google Drive account. It has no separate service backend that receives plaintext backup content and does not intentionally share backup content with other users or third-party services.

Retention and deletion

Recovery snapshots remain in the owner's Drive account until the owner deletes them. Automatic snapshot expiration is not configured. The owner controls deletion through restic repository maintenance or by removing the backup repository from Drive. Deletion and retention within Google's services are subject to Google's applicable settings and policies.

Revoke authorization

The owner can remove this client's access through Google Account third-party connections. Revoking access stops the client from accessing Drive through that authorization. It does not itself delete existing encrypted backup files.

This website

This site is hosted by GitHub Pages. It contains no application login, upload form, analytics scripts, advertising, or application-set cookies. GitHub may process connection information needed to host and protect the site under the GitHub Privacy Statement.

Contact and changes

For questions, contact the project owner through the GitHub profile. This page will be updated if the application's data handling changes.
